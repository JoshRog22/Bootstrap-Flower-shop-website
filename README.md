# Bootstrap Flower Shop Website

A responsive multi-page website designed for a fictional flower shop. The project demonstrates front-end web development, responsive design, Bootstrap integration, custom CSS styling, navigation, and visual asset management.

## Features

- Responsive business-style website layout
- Bootstrap-based navigation and page components
- Custom CSS styling
- Home and contact pages
- Responsive design for different screen sizes
- Custom images and visual assets
- Consistent branding and page styling

## Technologies & Tools Used

- HTML5
- CSS3
- Bootstrap
- Adobe Dreamweaver
- Adobe Photoshop

## Project Structure

- `index.htm` – Main website/home page
- `Contact-Us.htm` – Contact page
- `style.css` – Custom website styling
- `images/` – Website images and visual assets
- `bootstrap_dist/` – Bootstrap CSS and JavaScript dependencies

## Skills Demonstrated

- Responsive web design
- HTML5 page structure
- CSS styling and layout
- Bootstrap implementation
- Multi-page website development
- Navigation design
- Web asset organization
- Visual design and branding
- Adobe web design workflow

## Project Background

Originally developed as part of university coursework in web design and maintained here to demonstrate foundational experience with responsive website development, Bootstrap, HTML/CSS, and Adobe design tools.
